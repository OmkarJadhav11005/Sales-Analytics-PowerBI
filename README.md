# Sales Analytics Dashboard

## Project Overview
Interactive 2-page Sales Dashboard built using Power BI.

## Dataset
- 1,500 Orders
- ₹27.6M Revenue

## Tools Used
- Power BI
- DAX
- Excel

## Key KPIs
- Revenue
- Profit
- Profit Margin
- Orders
- Average Order Value

## Key Insights
- Online contributes 44% revenue.
- Electronics is the top profit category.
